# 👋 @ElKASec

Former full-stack web developer (DWWM certified), retraining in cybersecurity. Currently in year 3 (B3) at Otéria Cyber School, targeting the RNCP title **Expert en Cybersécurité**.

I learn a system by taking it apart: binaries, protocols, memory.

## 🎯 Current focus

| Domain | Detail |
|---|---|
| Reverse engineering | Static and dynamic analysis of ELF binaries (radare2) |
| x86-64 assembly | Reading and writing (Intel syntax), calling conventions, stack, registers |
| Rust | Low-level tooling, ownership model, memory safety, `unsafe` |
| Offensive security | TryHackMe rooms, Root-Me challenges |
| Web security | OWASP Top 10, authentication, injections (built on my web dev background) |
| Linux administration | Services, permissions, logs (journald, auditd) |

| Cloud (AWS, Azure) | IAM, networking (VPC/VNet), logging, common misconfigurations |
| SOC / Blue Team | Detection, log analysis, alert triage, SIEM, IOCs |
